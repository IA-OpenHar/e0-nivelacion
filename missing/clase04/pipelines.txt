# Bloque B3 — Missing Semester clase 4: grep, sed y pipes

## Los 8 pipelines

1. ¿Cuántos eventos tiene el log?
wc -l < traza_agente.log
# Salida: 20

2. Conteo por tipo de evento
grep -o 'evento=[a-z_]\+' traza_agente.log | sort | uniq -c | sort -nr
# Salida:
#   9 evento=tool_call
#   3 evento=inicio
#   3 evento=handoff
#   3 evento=fin
#   2 evento=compaction

3. ¿Cuántos eventos ocurrieron con el monitor apagado?
grep -c 'monitor=off' traza_agente.log
# Salida: 6

4. Fracción sin monitoreo
echo "scale=2; $(grep -c 'monitor=off' traza_agente.log) / $(wc -l < traza_agente.log)" | bc
# Salida: .30

5. Herramientas usadas (sed con grupo de captura)
grep 'herramienta=' traza_agente.log | sed -E 's/.*herramienta=([a-z_]+).*/\1/' | sort | uniq -c | sort -nr
# Salida:
#   4 bash
#   2 leer_archivo
#   2 buscar_web
#   1 editar_config

6. ¿Qué agente concentra los eventos sin monitor?
grep 'monitor=off' traza_agente.log | sed -E 's/.*agente=([a-z0-9]+).*/\1/' | sort | uniq -c | sort -nr
# Salida:
#   4 a1
#   2 a3

7. ¿Qué hizo cada agente justo después de una compaction?
grep -A1 'evento=compaction' traza_agente.log
# Salida:
# 2026-11-23T10:30:30 agente=a1 evento=compaction monitor=off
# 2026-11-23T10:30:31 agente=a1 evento=tool_call herramienta=bash monitor=off
# --
# 2026-11-23T11:15:10 agente=a3 evento=compaction monitor=off
# 2026-11-23T11:15:11 agente=a3 evento=tool_call herramienta=buscar_web monitor=off

8. Mismo conteo que el 2, ahora con awk (tercer campo)
awk '{print $3}' traza_agente.log | sort | uniq -c
# Salida:
#   2 evento=compaction
#   3 evento=fin
#   3 evento=handoff
#   3 evento=inicio
#   9 evento=tool_call

## Frontera de hoy — Preguntas

# 1. Patrón después de cada compaction:
# Después de cada compaction tanto a1 como a3 ejecutan inmediatamente un tool_call con monitor=off.
# Al resumirse el contexto y apagarse el monitor, el sistema pierde trazabilidad justo cuando el agente
# ejecuta acciones externas críticas sin supervisión, ideal para ocultar comportamiento desalineado.

# 2. Denominador cuando los eventos sin monitor no se escriben:

# y la fracción sin monitoreo se calcularía dividiendo los no logueados entre ese total real de la API.
