# e0-nivelacion
![Tests](https://github.com/IA-OpenHar/e0-nivelacion/actions/workflows/tests.yml/badge.svg)

Etapa 0 (nivelación) de mi plan de estudios de Ingeniería de IA, Ciencia de Datos y Robótica.

- `py4e/`: ejercicios de Python for Everybody
- `missing/`: ejercicios de The Missing Semester (MIT)
- `proyectos/`: mini-proyecto de cada viernes
- `robotica/`: simulaciones de física para robótica

Pruebas de la calculadora:
`python3 proyectos/calculadora/test_calculadora.py`
Pruebas de todo el repositorio:
`python -m pytest`
Pruebas del mini-proyecto de frecuencia:
`python3 proyectos/frecuencia_palabras/test_frecuencia.py`
